## Experiment: E-007 — Corrupted-output regression tests for scorers

- **Date:** 05.09.2026
- **Status:** completed
- **Theory:** Proxy scorers must reject deliberately corrupted outputs — edge cases where the scorer's extraction logic could misfire (e.g. "correct root" declaration overriding a named-but-wrong root, verb negation, rejection markers, heading spam, missing frontmatter). If any corrupted case passes, the proxy is too lenient and will give false learning signals to SkillOpt.
- **Hypothesis:** H-007: "scorer_accuracy >= 0.90"

Combined with 32 baseline cases = 40 total. Also includes a meta_root regex fix: `.{0,60}?` → `.*?` in the "correct root" pattern to handle intervening words like "would be under".
