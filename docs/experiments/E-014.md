# Experiment Record: E-014

## Experiment: E-014 — Audit hook suppresses self-feed from its own trail

- **Date:** 08.09.2026
- **Status:** completed
- **Theory:** The audit hook's notable-event detector fires on trigger phrases (TODO, "pending", "next step") wherever they appear — including when the tool call targets the audit trail itself (hook-audit.log, docs/code-docs, .metodoloji). Viewing the trail then creates new pending docs, which re-enter the trail: a self-feeding loop (observed live: terminal output containing the repo path "metodoloji" produced spurious pending docs). Suppressing detection when the target/output is the trail breaks the loop at the shared detector.
- **Hypothesis:** H-014: "trail_suppress_rate >= 0.90"
- **Measurement Metrics:** trail_suppress_rate >= 0.90
- **Experiment Design:** bench_audit_selffeed.py builds 100 trail-targeting probes (trail path/command/output, each carrying a trigger phrase that fires on non-trail targets) and calls the real _detect_notable_events; rate = probes yielding zero events / 100. Two non-trail controls must still fire.
- **Sample Size n:** 100
